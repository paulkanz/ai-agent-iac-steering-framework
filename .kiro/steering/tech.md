# Technical Standards, Guardrails & Trap Registry

> **Purpose:** Pre-empts subtle operational failures, prevents tool-induced state corruption, and enforces hard NIST SP 800-53 Rev 5 / CIS compliance baselines on all code generated by AI agents.

---

## 1. Tooling: OpenTofu vs. Terraform (The Provider Lock Trap)

> [!CAUTION]
> **THE REGISTRY LOCK MISMATCH TRAP:**  
> When operating with OpenTofu CLI reporting as `terraform`, OpenTofu defaults to `registry.opentofu.org`. However, committed `.terraform.lock.hcl` files typically pin `registry.terraform.io`. If an agent allows `init` to flip the lock file to `registry.opentofu.org`, remote state plans fail catastrophically across multiple environments with `Move Resource State Not Supported`.

### Agent Rules for Provider Locks:
1. **Never Flip Provider Namespaces:** Agents must NEVER commit a `.terraform.lock.hcl` where provider origins flip from `registry.terraform.io` to `registry.opentofu.org`.
2. **Preserve Committed Checksums:** Retain both `zh:` and `h1:` provider hashes when updating provider constraints.
3. **State Drift Remediation:** If provider registry drift occurs in remote state, remediate using `terraform state replace-provider`, never an unguided `terraform init -upgrade`.

## 2. Hard Compliance Gates (NIST SP 800-53 Rev. 5 & CIS)

All HCL code generated by agents MUST pass **NIST SP 800-53 Rev. 5 (Moderate/High)** and **CIS AWS Foundations Benchmark v3.0** checks before being presented.

### 2.1 Identity & Access Management (NIST AC-2, AC-3, AC-6)
* **Zero Inline Policies (`iam-no-inline-policy-check`):**
  * ❌ **NEVER USE:** `resource "aws_iam_role_policy"` (inline). Conformance packs flag this as a critical audit regression.
  * ✅ **ALWAYS USE:** `resource "aws_iam_policy"` (customer-managed) + `resource "aws_iam_role_policy_attachment"`.
* **Explicit Scoping:** Scope IAM resource blocks to explicit ARNs. Agents must NEVER generate `Resource = "*"` on data-plane or destructive actions.

### 2.2 Network Boundary & Zero-Trust (NIST SC-7, AC-4)
* **Security Group Cycle Prevention:**  
  * ❌ **NEVER USE:** Inline `ingress` or `egress` blocks inside `aws_security_group` that cross-reference other security groups (causes perpetual Terraform plan recreation cycles).
  * ✅ **ALWAYS USE:** Independent `aws_vpc_security_group_ingress_rule` and `aws_vpc_security_group_egress_rule` resources.
* **Workload Isolation:** Container workloads must run in private subnets with `assign_public_ip = false`. Public internet ingress is strictly reserved for ALBs and WAFs.
* **Default Security Group Lockdown (CIS 5.1):** All default VPC security groups must strip all inbound and outbound rules.

### 2.3 Cryptography & At-Rest Protection (NIST SC-8, SC-12, SC-13, SC-28)
* **Customer Managed Keys (CMK):** Every datastore (RDS, Aurora, ElastiCache, S3, ECR, CloudWatch Log Groups, Secrets Manager) must be encrypted using dedicated KMS CMKs with annual automatic key rotation enabled (`enable_key_rotation = true`).
* **Enforced In-Transit Encryption:** S3 bucket policies must explicitly reject non-TLS requests (`aws:SecureTransport = false`). Load balancers must enforce TLS 1.2+ modern AEAD cipher suites (`ELBSecurityPolicy-TLS13-1-2-2021-06`).

### 2.4 Storage & Supply Chain Integrity (NIST CM-8, SR-4, SI-3)
* **Immutable ECR Repositories:** All ECR repositories must enforce `image_tag_mutability = "IMMUTABLE"` and `scan_on_push = true`.
* **S3 Public Access Block:** All S3 buckets must enable all 4 public access block flags (`block_public_acls`, `block_public_policy`, `ignore_public_acls`, `restrict_public_buckets`).

## 3. Operational Anti-Patterns & Log Traps

* **CloudWatch Log Metric Queries:**  
  `aws logs filter-log-events` returns per-page counts, not totals. Agents writing diagnostic scripts must use CloudWatch Logs Insights queries (`stats count() by bin(1h)`) to report accurate totals.
* **CloudTrail Throttling:**  
  `cloudtrail lookup-events` throttles under rate-limiting and only covers management events. For data events (e.g. S3 object plane calls), agents must direct queries to CloudTrail CloudWatch Log Groups.
